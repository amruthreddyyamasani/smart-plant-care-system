# smart-plant-care-system
Smart ESP32 plant monitor using DHT22, LDR, and potentiometer in Wokwi. Evaluates temp, humidity, light, and soil metrics to detect risks like root rot, frost, and leaf scorch. Publishes real-time JSON updates to MQTT every 5s. Deliverables: GitHub repo with sketch.ino, circuit diagram, README, Wokwi link, and demo video.
